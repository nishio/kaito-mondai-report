# KAITO問題 ブロードリスニング分析（公開レポート）

2026年10月の **「#KAITO タグ被り騒動」**（King & Prince・髙橋海人のソロ名義「KAITO」と、20年続く VOCALOID「KAITO」の `#KAITO` タグ衝突）をめぐる、公開ウェブ上の **997件の意見** を **広聴AI（kouchou-ai）** でクラスタリングし、MVコメント1,340件やX調査で「海外ファン由来」説などを**ファクトチェック**した独立レポートです。

**公開ページ**: https://nishio.github.io/kaito-mondai-report/

## このレポートは
- 公開ウェブ上の投稿・報道・まとめ・Q&A・掲示板・百科・海外翻訳まとめなど **114ソース** から集めた意見を、**匿名化・要約**し、機械的にクラスタリングした「ブロードリスニング」のスナップショット（観測 as-of 2026-10-16）。賛否を**両論併記**します。
- 加えて、swim? 公式MVの**コメント1,340件**とX調査2系統（個人調査＋Grok）を観測データに、SNSで広まった説を段階評価（△誇張／✕裏付けなし／?確認されず）で**ファクトチェック**します。

## このレポートではない
- 代表性のある**世論調査ではありません**（収集源に偏りがあります）。
- 特定個人の断定や、誹謗中傷・脅迫の再掲ではありません（**文面・アカウントIDは不掲載**）。
- 確定した事実認定ではありません（進行中・二次情報を含みます）。

## 手法
- **分析**: 広聴AI（[kouchou-ai](https://github.com/digitaldemocracy2030/kouchou-ai)）analysis-core。ローカル多言語埋め込み（paraphrase-multilingual-mpnet）＋ UMAP ＋ Ward 階層クラスタリング（8/24/72 の3層）。
- **ラベル**: クラスタ名は各クラスタの代表意見から人手で付与。
- **可視化**: 単一ページの静的HTML（外部依存なし）。配色は色覚多様性に配慮して検証済み。

## 倫理・公開境界
脅迫・殺害予告・誹謗中傷の文面、私人の氏名・アカウントIDは一切掲載しません。公人・公式・権利元の公開済み発信のみを出典とします。**個別意見の全件データや生ソース一覧は公開しません**（本リポジトリには集計・匿名代表意見のみを収録）。

## ファイル
- `index.html` — レポート本体（単一ページ）
- `data.js` — 集計・匿名代表意見データ（クラスタ別）
- `cards.html` — X/OGP カード生成（`?c=1..5`、1200×675）
- `render_cards.mjs` — カードを `social/card1..5.png` に書き出すスクリプト
- `social/card1..5.png` — OGP/Twitter カード画像

## OGPカードの再生成（Chromium が動く環境で）
```bash
npm i puppeteer
node render_cards.mjs    # social/card1..5.png を更新
```
`cards.html` の文言を変えたら再実行して PNG を更新する。
